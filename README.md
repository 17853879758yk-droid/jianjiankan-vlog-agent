# 剪剪看 Vlog 创作 Agent

> 一个帮助 Vlog 创作者把模糊灵感转化为可确认、可修改的剪辑方向的 Agent Demo。

## 项目概览

许多创作者知道自己想要“有成长感”“更像电影”或“不要太套路”，却很难把直觉翻译成可执行的剪辑指令。剪剪看将这类自然语言需求拆解为创作意图、剪辑方向和执行计划，让用户在生成前看见并确认关键创作决策。

本项目以 Coze Code 原型验证 Agent 的核心决策链路。当前 Demo 使用预设素材和记忆数据，重点验证创作判断与交互流程，非实际视频渲染系统。

## 我负责的工作

- 调研创作 Agent 产品与用户反馈，归纳“语义理解不等于创作意图理解”的核心问题。
- 定义 MVP 产品范围、用户流程、功能优先级与验收标准。
- 设计 Agent 决策机制：意图理解、创作解释、方向探索、确认与局部修订。
- 制定 MOS 评测标准与 Golden / Edge Case，用于验证 Agent 是否遵循用户意图。
- 使用 Coze Code 搭建交互原型。

## 核心设计

### 1. 从自然语言到创作决策

`用户输入 → 意图理解 → 创作解释 → 方向卡片 → 用户确认 → 修订 → 执行计划`

Agent 不只将指令映射为工具调用，还会解释最终呈现应有的节奏、结构、素材取舍与情绪氛围。例如，“有成长感”不会被当作单一滤镜，而会被转化为可供用户比较的多种剪辑方向。

### 2. 用方向卡片降低表达成本

当用户没有明确方案时，Agent 提供 2–3 个在结构、节奏或叙事角度上显著不同的方向，包含一句话感觉、核心判断和素材取舍依据。用户可以基于某一方向继续局部修改，而无需重新描述需求。

### 3. 记忆是默认先验，不是永久指令

系统区分一次性偏好、会话偏好、稳定习惯和长期审美倾向。当前明确指令优先于历史记忆；当用户希望突破既有风格时，Agent 会降低历史偏好的影响。

### 4. 确认后再执行

在输出剪辑计划前，Agent 会展示创作判断，避免“看似完成了工具调用，却偏离最终创作效果”的情况。修订默认只影响当前任务，除非用户明确要求记住。

## 原型验证范围

| 已验证 | 暂未覆盖 |
| --- | --- |
| 模糊需求下的方向探索 | 实际视频渲染与复杂特效 |
| 意图确定性判断 | 真实素材理解与数据库记忆 |
| 探索、复用与突破习惯三种模式 | 多 Agent 协作 |
| 方向卡片、局部修订与确认流程 | 面向生产环境的权限与性能体系 |

## 架构思路

系统由意图理解、记忆管理、创作解释、模式决策、计划执行和质量闸门组成。所有执行计划都应可追溯至已确认的创作方向，避免用户自然语言直接、不可解释地触发底层工具。

## 评测方式

评测优先检查三件事：

1. 是否正确理解用户的创作目标，而非只完成字面操作；
2. 在探索与执行之间是否切换得当；
3. 是否保留用户已确认的方向，并只修改用户要求变化的部分。

典型场景包括：模糊需求、复用上一次的感觉、突破既有偏好、明确时长与首尾镜头要求、以及用户要求对已选方向作局部修改。
